# Decisions

One file per non-obvious choice: why we did it this way, what we rejected, and what would make
us change our mind.

**This is the highest-value directory in the repo.** Not because decisions are hard to make,
but because they are cheap to *re-litigate*. Without a record, the same three proposals come
back every few months, each time costing an hour of argument that was already had.

## Rules

- **Numbered, never renumbered.** `0001-`, `0002-`. The number is a permanent address.
- **Immutable once merged.** A decision that turns out wrong gets a *new* decision that
  supersedes it, with a link both ways. Editing history hides the reasoning that led there.
- **Record what was rejected, and why.** This is the part that saves time later. A decision
  doc that only states the winner is half a document.
- **Write the trigger.** "What would make us revisit this" turns a decision from dogma into a
  standing hypothesis.

## Before proposing anything

Grep this directory first. If the idea is already recorded as rejected, either accept it or
bring new evidence — and new evidence means a new decision doc, not an argument.
