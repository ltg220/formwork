# Archive

Completed work, closed issues, and shipped designs.

## Why this exists

Documents that only grow become swamps, and a swamp is functionally the same as having no
documentation — nobody reads it, so nobody trusts it, so nobody updates it.

The live docs (`known-issues.md`, `roadmap.md`, `designs/`) stay short by moving finished
things here. Nothing is deleted; it is just no longer in the way.

## What goes here

- Closed issues worth remembering — the diagnosis, not just the fix
- Shipped design docs, with an outcome note at the top: **what turned out to be wrong**
- Completed roadmap phases
- Superseded decisions stay in `docs/decisions/` instead, marked superseded, because their
  numbers are permanent addresses that other documents link to

## Rules

- Add a one-line outcome at the top of anything archived, dated.
- Do not maintain archived documents. They record what was believed then. Correcting them
  destroys the only useful thing they contain, which is the reasoning of the time.
